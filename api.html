API Documentation

Integrate RX Player's movie and music database into your website or app.

Authentication

Pass your API key in the URL parameter key OR in the header X-API-Key.

https://rxplayer-indol.vercel.app/api/v1/movie/details?id=969681&key=YOUR_API_KEY
Movies & TV Shows
GET /api/v1/movie/details
ParameterTypeDescription
id REQUIREDIntegerTMDB Movie or TV ID (e.g., 969681)
typeStringmovie (default) or tv
GET https://rxplayer-indol.vercel.app/api/v1/movie/details?id=969681&type=movie&key=YOUR_KEY
Music Search
GET /api/v1/music/search
ParameterTypeDescription
q REQUIREDStringSong or Artist name (e.g., arijit singh)
GET https://rxplayer-indol.vercel.app/api/v1/music/search?q=arijit&key=YOUR_KEY
Embed Players (No API Key Needed)

You can directly embed these iframes into your website.

Movie Embed:

<iframe src="https://rxplayer-indol.vercel.app/embed-movie.html?id=969681&type=movie" width="800" height="450" frameborder="0" allowfullscreen></iframe>

Music Embed:

<iframe src="https://rxplayer-indol.vercel.app/embed-music.html?query=arijit" width="100%" height="120" frameborder="0"></iframe>
